# Project Context

- Mission: make the game loop cheap to build, run, see, drive, and verify for an agent without a monitor.
- Core fantasy: a tiny hackable engine with Unreal-like building blocks and no editor dependency.
- Target feeling: deterministic iteration with visible evidence after every change.
- Pillars: thin APIs, seeded simulation, headless observability, reusable samples, small reviewed slices.
- Constraints: solo-developer scale, C++23, CMake/Ninja, raylib, Box2D, isolated Box3D, no unnecessary dependencies.
- Current direction: evolve the scene/runtime foundation before adding breadth to the editor or tooling.
